The visual lessons teach the "what/why." This is the "build & drill" half — your runnable labs (all tested + passing), the Azure interview Q&A, and the planning CSVs. Everything lives as files in your Kiro workspace; this page is the map.

⭐ THE PREP LOOP (do this per topic)

  1. Read the visual lesson (understand the concept)
  2. Build — open the matching lab, delete the solution, write it yourself, run it green
  3. Drill — say the Q&A answer aloud without reading

Reading alone builds recall. The labs build the "can you actually code it" muscle interviews test. Do all three.

How to open these: they're files/folders in your workspace, not web pages. Open them in Kiro's file explorer at the paths shown. Run a lab with python <file>.py from its folder.
